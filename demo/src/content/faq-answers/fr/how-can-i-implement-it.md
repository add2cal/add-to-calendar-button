---
question: 'Comment installer Add to Calendar Button ?'
category: 'setup'
---

Installez le paquet ou chargez-le via un CDN, importez le script et ajoutez un élément `<add-to-calendar-button>` avec les attributs de votre événement. Ce Web Component fonctionne en HTML, avec les frameworks, les outils de création de sites et WordPress. Consultez [l'installation](/fr#installation).

Core Engine Capabilities

Built for edge cases & real-world events

Calendar APIs and .ics specifications require careful platform handling. We solved every browser, protocol, and timezone anomaly so you don't have to.

1. All Major Calendars

Direct deep-links for web calendars (Google, Outlook, Office 365, Yahoo) alongside validated RFC 5545 .ics files for Apple and native desktop clients.

View Calendar Examples →

2. Flexible Event Types

Supports all-day events, multi-date schedules, recurring RRULE intervals, subscriptions, and dynamic date parameters updated via JavaScript.

See Configuration Docs →

3. Time Zones & DST

Detects the visitor's local browser timezone automatically and converts UTC offsets seamlessly, including Daylight Saving Time transitions.

Timezone Details →

4. Browser & Webview Handling

Rigorously tested across iOS Safari popup blockers, Android Chrome, in-app mobile webviews (Instagram, LinkedIn), and Outlook webmail protocols.

Try it in the playground →

5. Styling & 44 Languages

Custom themes, CSS custom variables, custom button labels, and automatic i18n localization in 44 languages based on browser locale.

Language List →

6. Accessibility & Privacy

WCAG AA compliant with keyboard and screen-reader support. 100% client-side execution, strict GDPR environments, and CSP nonce support.

Security Docs →
